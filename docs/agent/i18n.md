# Dokumentacja Domenowa: Internacjonalizacja (Faza 10)

Aplikacja działa po angielsku (domyślnie) i po polsku. Zamiast `next-intl` użyto lekkiego, własnego rozwiązania (`src/i18n/`): aplikacja jest klientowa i zalogowana, nie ma tras per język, a `next-intl` + Cache Components w Next 16 wymagałby przebudowy layoutów.

## Zasady
- **Słowniki:** `src/i18n/messages.ts` (`pl` jest źródłem typów, `en: Record<MessageKey, string>` — brak klucza w `en` to błąd kompilacji). Parametry `{name}`. Test `i18n.test.ts` pilnuje identycznych kluczy i parametrów.
- **Użycie:** `const { t, tDynamic, locale, units } = useI18n()` (`I18nProvider` w `src/app/layout.tsx`). Nigdy nie wpisuj tekstu UI na sztywno — dodaj klucz do obu języków.
- **Wybór języka:** zapisany w `localStorage` (`spanko.locale`) → język przeglądarki (pl → pl, reszta → en) → `en`. Przełączniki EN/PL i ml/oz w panelu użytkownika `/settings` (`src/components/settings/PreferencesMenu.tsx`), dostępnym z ikony konta w nagłówku dashboardu. `<html lang>` ustawiany po stronie klienta.
- **Treści celów:** `src/lib/goal-copy.ts` (PL/EN) — opisy zadań, metod, blokerów gotowości, czerwonych flag; używane też przez awaryjną ścieżkę coacha na serwerze.
- **Dane zapisujemy zawsze neutralnie:** tagi dnia pozostają kluczami (`ząbkowanie`, `szczepienie`…), tłumaczone w UI przez `tDynamic("tag.<klucz>", klucz)`; własne tagi wyświetlają się bez zmian.
- **Jednostki:** objętość zapisywana w **ml**; wyświetlanie w ml lub oz (`spanko.units`, domyślnie oz tylko dla `en-US`). Presety butelki w oz mapują się na ml (`bottlePresets`). Godziny: `toLocaleTimeString([])` — 12/24 h wg urządzenia. Doba fizjologiczna: strefa dziecka (`children.timezone`).
- **AI:** `evaluate-insights` i `goal-coach` dostają `locale` i proszą model o odpowiedź w tym języku. Teksty awaryjne silnika (tytuły i wyjaśnienia drzew diagnostycznych w `diagnosticTrees.ts`) są nadal po polsku — do przetłumaczenia (kody diagnoz są stabilne, więc wystarczy mapa kod → tekst).
- **Poza zakresem:** Panel Admina (`/admin`) pozostaje po polsku (narzędzie wewnętrzne); dane demonstracyjne DEV (`devFixtures.ts`).
